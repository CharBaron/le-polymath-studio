- De Brigard, F. (2010). If you like it, does it matter if it's real? *Philosophical Psychology*, 23(1), 43-57 : 72 étudiants à qui l'on dit qu'ils sont déjà branchés ; sans précision sur leur vie réelle, 54 % veulent se débrancher (46 % restent) ; si la vie réelle est celle d'un détenu en prison de haute sécurité, 13 % seulement se débranchent (87 % restent).
